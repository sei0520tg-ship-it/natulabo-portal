## 主要機能サマリー

| 機能 | 説明 |
|------|------|
| 招待制会員登録 | 招待コード必須・Manus OAuth認証 |
| 学習動画ライブラリ | YouTube iframe API・視聴進捗保存・続きから再生 |
| トピックスカルーセル | ダッシュボード上部・最大5件・自動再生・ループ |
| 体験談 | 管理者が追加・公開/非公開管理 |
| クラフトレシピ集 | カテゴリ別・検索・詳細モーダル |
| イベントカレンダー | 月次表示・Google Form連携 |
| 外部リンク集 | カテゴリ別リンクカード |
| 閲覧ログ | ページビュー・ログイン・動画視聴の記録 |
| 管理画面 | 全コンテンツの追加・編集・削除・公開管理 |
