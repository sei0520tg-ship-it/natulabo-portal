# NatuLabo共有カレンダー利用ガイド

更新日: 2026-08-18

## 概要

NatuLaboのイベント管理画面で公開した予定は、iCalendar形式の購読フィードに自動反映されます。会員が一度カレンダーを購読すると、その後のイベント追加・日時変更・公開停止も利用中のカレンダーアプリ側で更新されます。

## 会員向け導線

イベントページ（`/calendar`）に、次の導線を実装しています。

| 導線 | 用途 |
|---|---|
| Googleカレンダーで購読 | Googleカレンダーの「URLで追加」に登録する共有フィードURLを開きます。 |
| Apple / Outlookで購読 | `webcal://` 形式で共有フィードを購読します。 |
| 個別予定を追加 | 各イベントをGoogleカレンダーへ追加、または`.ics`ファイルとして保存します。 |

## フィードURL

公開時の共有フィードURLは以下です。

```text
https://natulabo-jgdafshb.manus.space/api/calendar/natulabo.ics
```

Googleカレンダーでは、左メニューの「他のカレンダー」→「URLで追加」から上記URLを登録します。Appleカレンダー・Outlookでは、イベントページの「Apple / Outlookで購読」ボタンを使用します。

## 管理者向け運用

1. 管理画面のイベント管理で予定を追加・編集します。
2. 会員へ公開する予定は「公開」に設定します。
3. 保存した変更は共有フィードに即時反映されます。外部カレンダー側の再取得タイミングはサービスにより異なります。

非公開イベントはフィードおよび個別`.ics`ファイルに含まれません。

## 技術検証結果

- `GET /api/calendar/natulabo.ics` は `200` と `text/calendar; charset=utf-8` を返却。
- 個別予定ファイル `GET /api/calendar/events/:id.ics` も `200` を返却。
- フィード内でカレンダー名・イベント名・開始日時を確認。
- VitestでiCalendarのエスケープ、UTC表記、公開予定のみの配信、GoogleカレンダーURLを検証。
