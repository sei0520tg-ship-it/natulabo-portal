# YouTube 自動連携 セットアップ手順

会員向け「学習動画」ライブラリと、ダッシュボードの「最新動画」セクションを、
YouTube の再生リストから自動更新するための設定手順です。

---

## 仕組み

```
YouTube 再生リスト（限定公開）
        │  YouTube Data API v3 (playlistItems.list)
        ▼
/api/scheduled/syncYoutube   ← cron が毎時POST
        │
        ▼
videos テーブル（youtubeVideoId で照合して upsert）
        │
        ├─→ /videos          会員向け動画ライブラリ
        └─→ ダッシュボード     「最新動画」セクション（isLatest）
```

### なぜ再生リスト経由なのか

チャンネルのアップロード一覧（`UU...`）は、API キー経由だと**公開動画しか返りません**。
NatuLabo の動画は限定公開のため、そのままでは 1 本も取得できません。

再生リストに入れておけば、限定公開の動画でも一覧取得・埋め込み再生ができます。
これが限定公開を維持したまま自動化する唯一の現実的な方法です。

---

## 手順 1. YouTube 側で再生リストを作る

1. YouTube Studio →「再生リスト」→「新しい再生リスト」
2. 名前は任意（例：`NatuLabo 会員向け動画`）
3. 公開設定は **「限定公開」** にする（「非公開」だと API から取得できません）
4. 既存の動画をすべてこの再生リストに追加する
5. 再生リストの URL から ID を控える
   `https://www.youtube.com/playlist?list=PLxxxxxxxxxxxx` → `PLxxxxxxxxxxxx` の部分

> **今後の運用**：新しい動画をアップしたら、この再生リストに追加するだけで
> サイトに自動で反映されます。YouTube Studio のアップロード設定で
> 既定の再生リストに指定しておくと、追加操作すら不要になります。

## 手順 2. YouTube Data API のキーを取得する

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」→ **YouTube Data API v3** を有効化
3. 「認証情報」→「認証情報を作成」→ **APIキー**
4. 作成したキーを「キーを制限」→ API の制限で **YouTube Data API v3 のみ**に絞る

無料枠は 1 日 10,000 ユニットです。本連携は 1 回の同期で数ユニットしか使わないため、
毎時実行しても上限には届きません。

## 手順 3. Manus に環境変数を設定する

Manus のプロジェクト設定（環境変数）に以下を追加します。

| 変数名 | 必須 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `YOUTUBE_API_KEY` | ○ | 手順 2 で取得した API キー | — |
| `YOUTUBE_PLAYLIST_ID` | ○ | 手順 1 の再生リスト ID（`PL...`） | — |
| `YOUTUBE_DEFAULT_CATEGORY` | | 新規取り込み時のカテゴリ名 | `学習動画` |
| `YOUTUBE_LATEST_COUNT` | | 「最新動画」として扱う本数 | `3` |

> **APIキーは絶対にリポジトリへコミットしないでください。**
> このリポジトリは public です。キーは Manus の環境変数にのみ置きます。

## 手順 4. DB マイグレーションを流す

`videos` テーブルに `youtubeVideoId` / `publishedAt` / `syncedAt` を追加します。

```bash
pnpm run db:push
```

## 手順 5. デプロイして cron を登録する

cron はデプロイ済みの本番 URL に対して POST するため、**先にデプロイが必要**です。

デプロイ後、Manus のサンドボックス端末で 1 回だけ実行します。

```bash
manus-heartbeat create --name sync-youtube --cron "0 0 * * * *" --path /api/scheduled/syncYoutube --description "YouTube再生リストを毎時同期"
```

cron 式は 6 桁（秒つき・UTC）です。`0 0 * * * *` は毎時 0 分。
1 日 1 回で十分なら `0 0 21 * * *`（日本時間 朝 6 時）などにしてください。

登録後は Manus のダッシュボードから実行履歴の確認・一時停止・Run Now ができます。

## 動作確認

管理画面の「動画管理」に **YouTube自動連携** パネルを追加しました。

- 環境変数が未設定なら警告が出ます
- 「今すぐ同期」ボタンで cron を待たずに手動実行できます
- 同期済み件数と最終同期日時が表示されます

同期結果は `取得 / 新規 / 更新 / 紐付け / 非表示` の内訳がトーストで出ます。

---

## 同期の挙動（上書きルール）

| 項目 | 扱い |
| --- | --- |
| タイトル・説明・サムネイル・URL・公開日 | **YouTube 側を正**として毎回上書き |
| カテゴリ・公開フラグ | **管理画面の編集を尊重**（既存行は維持） |
| `sortOrder` | 公開日の新しい順に 0, 1, 2... を自動採番 |
| `isLatest` | 新しい上位 `YOUTUBE_LATEST_COUNT` 本に自動で付け替え |

その他の仕様は以下のとおりです。

- **手動登録した動画には一切触れません**（`youtubeVideoId` が `null` の行は対象外）
- 初回同期時、管理画面から手で登録済みの YouTube 動画は URL から照合して自動で紐付けます（二重登録になりません）
- 再生リストから外した動画は**非公開になるだけで削除されません**（会員の視聴履歴を残すため）
- 非公開・削除済みの動画は取り込みません

## トラブルシューティング

| 症状 | 原因と対処 |
| --- | --- |
| `YouTube API 403` | API キーの制限設定、または 1 日の割り当て超過を確認 |
| `YouTube API 404` | `YOUTUBE_PLAYLIST_ID` の誤り。再生リストが「非公開」になっていないか確認 |
| 取得 0 件 | 再生リストが空、または全動画が「非公開」。「限定公開」に変更してください |
| 管理画面に警告が出る | 環境変数が本番に反映されていません。設定後に再デプロイが必要です |
