## 1. プロジェクト概要

NatuLabo Portal は、**dōTERRA愛用者向けの招待制・会員制ポータルサイト**です。会員が日常的に必要とする情報（学習動画、イベント情報、外部リンク、体験談、レシピ）を一元管理し、管理者が継続的にコンテンツを追加・更新できる仕組みを提供します。

ターゲットユーザーは主に20〜40代の女性で、ナチュラル・健康・上品なデザインを重視しています。スマートフォンでの利用を主軸に設計されています。

## 2. 要件定義

### 2.1 機能要件

| 機能カテゴリ | 要件内容 |
|-------------|---------|
| **会員登録** | 招待制（招待コード必須）、Manus OAuthによる認証 |
| **ログイン** | Manus OAuthを使用したシングルサインオン |
| **管理者** | 複数管理者対応（role: admin） |
| **動画** | YouTube iframe API使用、視聴進捗保存・続きから再生 |
| **画像管理** | 管理画面から差し替え可能（S3ストレージ） |
| **外部リンク** | カテゴリ別リンク集、管理画面から追加・編集・削除 |
| **体験談** | 管理者が追加・編集・削除・公開/非公開切り替え |
| **レシピ集** | カテゴリ別・カード形式・詳細モーダル・検索機能 |
| **カレンダー** | イベント・講座の一覧表示、Google Form連携 |
| **トピックス** | ダッシュボード上部の横スワイプ式カルーセル（最大5件） |
| **閲覧ログ** | ページビュー・ログイン履歴・動画視聴ログの記録 |
| **招待コード管理** | 管理画面から発行・使用回数制限・有効期限設定 |

### 2.2 非機能要件

| 項目 | 要件 |
|------|------|
| **デザイン** | ナチュラル・健康・上品。B-VAXサイト参考のクリーム/ゴールド/フォレストグリーン配色 |
| **フォント** | Noto Serif JP（日本語）、Cormorant Garamond（英語見出し） |
| **レスポンシブ** | スマートフォン優先設計 |
| **認証** | 招待制会員のみアクセス可能 |
| **パフォーマンス** | 動画はYouTube外部配信を利用（サーバー負荷軽減） |

### 2.3 デザイン要件

参考サイト: [B-VAX](https://www.b-vax.com/)

カラーパレット:

| 色名 | 用途 | 値（OKLCH） |

| Gold | アクセント・ボーダー | oklch(0.750 0.100 75) |
| Forest Green | プライマリ・ボタン | oklch(0.420 0.092 150) |
| Brown | テキスト | oklch(0.300 0.040 60) |

## 3. 技術スタック

| レイヤー | 技術 |
|---------|------|
| **フロントエンド** | React 19 + TypeScript + Tailwind CSS 4 |
| **バックエンド** | Express 4 + tRPC 11 |
| **データベース** | MySQL / TiDB + Drizzle ORM |
| **認証** | Manus OAuth（protectedProcedure / adminProcedure） |
| **ストレージ** | Manus built-in S3（storagePut） |
| **動画** | YouTube iframe API |
| **ルーター** | wouter |
| **UIライブラリ** | shadcn/ui + Radix UI |
| **テスト** | Vitest |
| **ホスティング** | Manus Autoscale |
