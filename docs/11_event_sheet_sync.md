# イベント連携（Googleフォーム → スプレッドシート → サイト）セットアップ手順

チームがGoogleフォームからイベントを登録すると、サイトのカレンダーに自動で反映される仕組みです。
LINEでの手作業共有やスプレッドシートへの転記が不要になります。

---

## 仕組み

```
チームメンバー（約15人）
   │  Googleフォームで登録
   ▼
Googleフォーム（種別ごとに4種類＋その他）
   │  回答が自動で溜まる
   ▼
スプレッドシート（「ウェブに公開」でCSV配信）
   │  15分おきに取得
   ▼
/api/scheduled/syncEvents   ← cronがPOST
   │
   ▼
events テーブル
   │
   ├─→ /calendar        カレンダー（ドット表示・タップで詳細）
   └─→ ICS配信          Google / Apple / Outlook カレンダーへの購読
```

### 設計上のポイント

- **フォームの回答は編集・削除できる運用**（約15人に権限付与）を前提にしています。そのため同期は毎回の洗い替えではなく、**「フォーム送信日時」を鍵にした冪等な更新**にしています。行を編集しても鍵は変わらないので、重複せず内容だけが更新されます
- **シートから行を削除した場合は、イベントを削除せず非公開にします**。過去の予定を履歴として残すためです
- **管理画面から手で登録したイベントには一切触れません**（`sourceKey` が空の行は対象外）
- 入力された日時は**すべて日本時間として解釈**します。サーバーのタイムゾーンに依存しません

---

## 手順1. Googleフォームを作る

イベント種別ごとに分けます（例：本社イベント／オンライン講座／ワークショップ／セミナー／その他）。

各フォームに以下の質問を用意してください。**見出しの表記ゆれは吸収する**ので、下記と完全一致していなくても動きます。

| 必須 | 質問文の例 | 受け付ける表記 |
| --- | --- | --- |
| ○ | イベント名 | タイトル / 件名 / 予定名 |
| ○ | 開始日時 | 日時 / 開催日時 |
| | 終了日時 | 終了 |
| | 場所 | 開催場所 / 会場 |
| | 種別 | カテゴリ / 分類 |
| | グループ | 対象グループ / 対象 |
| | 詳細 | 説明 / 内容 / 備考 |
| | 申込フォームURL | 申込URL / リンク |
| | 公開 | 掲載 |

**開始日時の入力形式**：次のいずれでも解釈できます。

- `2026/08/22 19:00`
- `2026-08-22 19:00`
- `2026年8月22日 19:00`
- 「開催日」と「開始時刻」を別の質問に分ける形式

**「グループ」について**：`なちゅらぼ公式` `樹里エリー限定` のように入力すると、カレンダー上部に絞り込みタブが自動で出ます。1つも入力がなければタブは表示されません。複数グループを1つのカレンダーに集約するか分けるかは要検討事項でしたが、**この実装なら「集約して、タブで切り替える」形になっており、あとから運用で決められます**。

**「公開」について**：`いいえ` `非公開` `下書き` のいずれかを入れると非公開になります。空欄なら公開です。

## 手順2. スプレッドシートをCSV公開する

各フォームの回答スプレッドシートで操作します。

- メニューの **ファイル → 共有 → ウェブに公開**
- 「リンク」タブで、公開する対象に**該当のシート**を選ぶ
- 形式を **カンマ区切り形式（.csv）** に変更
- 「公開」をクリックし、表示されたURLを控える

URLは次のような形になります。

```
https://docs.google.com/spreadsheets/d/e/2PACX-xxxxxxxx/pub?gid=0&single=true&output=csv
```

> **注意**：この設定でシートの内容がURLを知っている人に読める状態になります。イベントの予定表なので通常は問題ありませんが、個人情報（申込者の氏名・連絡先など）が同じシートに入る場合は、**イベント情報だけを別シートに分けて**、そのシートのみを公開してください。

## 手順3. 環境変数を設定する

Manusのプロジェクト設定（環境変数）に `EVENT_SHEET_CSVS` を追加します。**1行に1シート**、`シート名|CSVのURL` の形式です。

```
本社イベント|https://docs.google.com/spreadsheets/d/e/xxx/pub?gid=0&single=true&output=csv
オンライン講座|https://docs.google.com/spreadsheets/d/e/yyy/pub?gid=0&single=true&output=csv
ワークショップ|https://docs.google.com/spreadsheets/d/e/zzz/pub?gid=0&single=true&output=csv
```

シート名は管理画面に表示されるだけで、動作には影響しません。

## 手順4. DBマイグレーションを流す

`events` テーブルに `groupName` / `sourceKey` / `syncedAt` を追加します。

```bash
pnpm run db:push
```

## 手順5. デプロイして cron を登録する

cronはデプロイ済みの本番URLに対してPOSTするため、**先にデプロイが必要**です。

デプロイ後、サンドボックスの端末で1回だけ実行します。

```bash
manus-heartbeat create --name sync-events --cron "0 0,15,30,45 * * * *" --path /api/scheduled/syncEvents --description "イベント用スプレッドシートを15分おきに同期"
```

cron式は6桁（秒つき・UTC）です。上記は15分おき。1時間おきで十分なら `0 0 * * * *` にしてください。

---

## 動作確認

管理画面の「イベント管理」に **スプレッドシート連携** パネルを追加しました。

- 環境変数が未設定なら警告が出ます
- 「今すぐ同期」ボタンで cron を待たずに手動実行できます
- 連携中のシート名、同期済み件数、最終同期日時が表示されます

同期結果は `シート数 / 取得 / 新規 / 更新 / 非公開 / 対象外` の内訳がトーストで出ます。

## トラブルシューティング

| 症状 | 原因と対処 |
| --- | --- |
| `CSVではなくHTMLが返りました` | 「ウェブに公開」が未設定です。手順2をやり直してください。共有設定（閲覧権限）だけでは足りません |
| `HTTP 404` | URLの誤り。`output=csv` が付いているか確認してください |
| 取得件数が0 | シートにヘッダ行しかない、または「イベント名」「開始日時」に相当する列が見つかっていません |
| 「対象外」が多い | イベント名か開始日時が空の行です。フォームの必須設定を確認してください |
| 時刻が9時間ずれる | 通常は起きません。ずれる場合は日時の入力形式を手順1の例に合わせてください |
| 削除したはずの予定が残る | 非公開になっているだけです（仕様）。完全に消すには管理画面から削除してください |
